Core Features

Six pillars of autonomy

Every component designed with privacy and control at its foundation.

🔧

HAL+

Hardware Adaptation Layer in Rust. Automatic driver detection and setup — one question max per notification, zero jargon.

✨

Hope Shell

Wayland-based interface with Deep Space aesthetic. Blazing fast Spotlight search powered by Phi-3.5-mini local AI.

🔐

Hope Vault

Full-disk LUKS2 encryption, Argon2id KDF, ephemeral swap keys, and RAM erasure on shutdown for Maximum mode.

🧠

Hope-Mind

Local AI inference with intelligent model loading. Granite 3.1 for deep work, automatic model unloading after 15min idle.

🎤

Hope Voice

Push-to-talk voice control with local Whisper. No wake words, no cloud transmission — pure privacy.

🔗

Polygone Integrated

End-to-end encrypted sync, distributed LLM inference, 4K screen casting under 50ms, and zero-config dev sharing.

Privacy Levels

Choose your threat model

Three tiers of protection, from everyday security to maximum operational security.

S

Standard

For everyday users who want solid security without friction.

  • DoH via Cloudflare
  • Hope-Mind local inference
  • Brave Shields active
  • LUKS2 full-disk encryption
R

Renforcé

Enhanced protection for sensitive work and communications.

  • DNS over Tor
  • Vault unlock-once mode
  • Clipboard auto-clear (2min)
  • FIDO2 / Passkeys native
M

Maximum

Full paranoia mode for high-risk environments.

  • Tor proxy mandatory
  • LUKS2 enforced always
  • RAM erasure on shutdown
  • No cloud connectivity
🚧

Custom

Roll your own threat model with granular controls.

  • Mix and match any tier
  • Custom encryption settings
  • Network policy per-app
  • Audit everything
